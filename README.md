# FitPro Market  
Premium Health & Fitness E‑Commerce Front-End

FitPro Market is a polished, responsive front-end e-commerce website built to showcase premium health, fitness, and recovery products. The project focuses on clean UI design, smooth interactions, accessibility, and a modern shopping experience across all devices.

---

## Features

### Hero Section  
A bold, high-impact hero introducing the brand with:
- Premium fitness messaging  
- Clear call-to-action buttons  
- Responsive layout (Google Developers, 2024)  
- Fast-loading visuals
- Mobile-first layout principles (Google Developers, 2024)

### Intro Video with Hover Controls  
A custom video player featuring:
- Raw emoji controls ( ▶ ❚❚ ↺ 🔇)  
- Controls that only appear on hover (Brinck, Scott and Wood, 2021)  
- Smooth fade-in animation (Google Material Design, 2024)  
- Mobile-friendly tap interaction  
- Skip Intro button  
- Custom volume and timeline sliders  

The video is included purely for design demonstration purposes.  
It shows that the website supports:
- Custom video integration  
- Custom UI controls  
- Hover-based interactions (Zhao and Stasko, 2020)  
- Responsive behaviour (Google Developers, 2024)  

### Featured Products  
A dynamic grid showcasing:
- Product cards with tilt animation  
- Category labels  
- Pricing  
- Add-to-cart and details buttons  
- Fully responsive layout (Bootstrap Team, 2024)
  

### Navigation  
A clean, accessible navigation bar with:
- Home  
- Products  
- About  
- Contact  
- Cart indicator with live count  

### Pop-Up Modal  
A reusable modal for product details:
- Dynamic product detail injection  
- Smooth open/close animations  
- Accessible interaction patterns 

### Modern UI Styling  
The entire site uses:
- Neon-accented gradients  
- Soft shadows  
- Rounded cards  
- Smooth hover transitions (Nielsen Norman Group, 2023)  
- Mobile-first responsive design (Google Developers, 2024)
